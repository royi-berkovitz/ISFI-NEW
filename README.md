# ISFI · דף נחיתה

דף נחיתה בעברית (RTL) למכון האסטרטגי לעתיד ישראל.

## מה יש כאן
- `index.html` · גרסה עצמאית של העמוד, כל הנכסים ארוזים בתוכה. זה הקובץ שמוצג ב-GitHub Pages.
- `ISFI Landing.dc.html` · קובץ המקור (Design Component). נפתח ישירות בדפדפן, צריך את `support.js` לצידו.
- `support.js` · סביבת ההרצה של קובץ המקור.
- `assets/` · תמונות, לוגואים וחיצי הסליידר.
- `icons/` · אייקונים.
- `CLAUDE.md` · הנחיות הפרויקט (עברית, RTL, Karantina + Heebo).

## GitHub Pages
1. מעלים את כל התיקייה לשורש הריפו.
2. Settings → Pages → Deploy from branch → `main` / root.
3. העמוד יעלה מ-`index.html`.

## גופנים
Karantina + Heebo, נטענים מ-Google Fonts.
